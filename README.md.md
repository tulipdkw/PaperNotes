## 🔬 研究方向简介

### 🧠 Interpretable Safety

研究如何通过可解释性方法理解和提升大语言模型的安全性。核心问题包括：

- 模型内部表示中的安全相关特征识别
- 机制可解释性（Mechanistic Interpretability）在安全对齐中的应用
- 模型行为归因与有害行为溯源

### 👁️ VLM Safety

聚焦于视觉语言模型（Vision-Language Models）的安全对齐问题。核心问题包括：

- 多模态越狱攻击（Jailbreak）与防御
- 视觉输入引发的安全漏洞分析
- 跨模态对齐与安全性评估
